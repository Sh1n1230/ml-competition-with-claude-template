# 指標定義

一次情報は `.references/METRIC.md`。ここには **CV でどう再現するか** を書く。

| 項目 | 内容 |
|------|------|
| 公式指標 | |
| 最適化方向 | Maximize / Minimize |
| 提出値の種類 | ラベル / 確率 / 数値 |
| ローカル実装 | `src/...` のメトリック評価関数 |
| 決定ルール | <!-- 閾値・クラス重み・argmax など。metric に合わせて必ず設計する --> |

## 注意

- **metric と学習の損失関数がズレる**のは普通。ズレを決定ルールで吸収する。
  （例: balanced accuracy → クラス重み付き学習 + per-class 閾値調整）
- 決定ルールの調整は OOF に過学習しやすい。**nested-CV ゲート**を通す。
