# 報告ガイドライン

詳細は `.claude/skills/analysis-reporting/SKILL.md`。ユーザーへの報告は**日本語**。

## 実験1件の報告

```
結論: <採用 / 不採用 とその理由を一文>
CV: <値> (fold別: ...)  / 前ベスト: <値> / 差分: <±>
変更点: <1つだけ>
所要時間: <学習時間>
次の一手: <1つ提案>
```

## 提出時の報告

```
提出: <ファイル> / note: <実験番号 + 構成 + CV>
検証: validate_submission.py 通過（行数・ID・値域）
予測分布: <train との比較>
残り提出枠: <n 回>
```

## 節目のまとめ

`analysis-reporting` の構成（結論 → 事実 → 仮定 → 解釈 → 制約）で、
再現情報（入力パス・スクリプトパス・出力パス・実行コマンド）を必ず添える。
